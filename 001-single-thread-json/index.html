What completion means

An acknowledgement follows parse, transform, serialization, and buffered append. Every 256 messages, it also follows a flush to the OS. No fsync is requested. Throughput includes queue drain and the final flush.

Fixed-rate latency starts at scheduled arrival, including admission backlog. Unlimited latency starts when a message enters the loader’s bounded buffer (window 1024). Neither is a disk-durability measurement.

Scenarios

  • A: short-lived message trees.
  • B: 8 extra parse/serialize passes with temporary trees.
  • C: grow a ring up to 1,000,000 message graphs, each with a two-way reference cycle; evicted graphs become collectible.

Controls and limits

  • One application thread. JVM GC and compiler threads share the handler’s single-core affinity.
  • Fresh process per run, warm-up in the same process, paired randomized language order.
  • Both use 65,536-byte file buffers and the ext2/ext3 filesystem.
  • Java heap maximum: 1536 MiB. Common process budget: 3072 MiB; cgroup v2 memory.max, swap disabled. CPython has no equivalent Xmx heap setting.
  • Python’s standard JSON module includes C code. Java uses the included generic JSON parser because the JDK provides no JSON parser. Functional equivalence is checked; bytes and object layouts can differ.
  • Hardware: AMD EPYC 7763 64-Core Processor. Shared CI and virtualization can add noise. Check the spread and generator CPU before drawing a conclusion.
